
# Kaermaksan Web Sitesi

Bu proje ücretsiz olarak GitHub Pages üzerinden yayınlanabilir.

## Kurulum

1. GitHub hesabı oluştur.
2. Yeni repository aç:
   - İsim: kaermaksan-site
3. Bu dosyaları yükle.
4. GitHub'da:
   - Settings > Pages
   - Branch: main
   - Folder: /root
5. Save butonuna bas.

Siten birkaç dakika içinde yayında olur.

Örnek adres:
https://kullaniciadi.github.io/kaermaksan-site/
